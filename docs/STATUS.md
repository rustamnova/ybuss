# Проверено 2026-10-31

## Работает

- Первый сервер: `yandexbus.service`, отдельный системный пользователь,
  Telegram long polling, автозапуск. Токен и личное состояние вне Git.
- Меню: прибытие, список названий, добавление ссылкой, удаление кнопкой.
- Прямое получение публичной страницы Яндекс Карт без Chromium. На контрольной
  остановке получены HTTP 200, шесть номеров автобусов и пять событий
  `Estimated`; возраст `currentTime` в одном из запросов — около 0,23 секунды.
- Время события берётся из `Estimated.value`, при его отсутствии из
  `Scheduled.value`. Прогноз и расписание подписываются отдельно.
- Кеш 30 секунд, общая пауза 300 секунд при ограничении, отклонение старого
  ответа. Перенаправления `yandex.ru → yandex.eu → yandex.com` проверены
  с сервера и разрешены только для HTTPS-страниц Карт.

## Ограничения

- Причина ответа `limited` в Chromium точно не установлена. Зафиксирована
  доступность данных через HTTP с того же сервера; браузер из пути бота убран.
- Публичная разметка и вложенные данные не являются стабильным API.
- Для части рейсов Яндекс отдаёт только расписание. Наличие `Estimated`
  подтверждает прогноз Яндекса, но не гарантирует фактическое время приезда.
- Пока личный бот с одним владельцем; отдельные кабинеты нескольких
  пользователей не реализованы. На новой установке владелец — первый `/start`.
- Долговременная доступность источника ещё не подтверждена наблюдением.

схемы чинить парсер по новому публичному ответу, сохраняя различие между
прогнозом и расписанием. При ограничении выдерживать паузу.
